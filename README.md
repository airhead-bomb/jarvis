# 자비스(JARVIS) — 텔레그램 봇 + 설치형 웹앱(PWA)

이제 자비스는 두 가지 방법으로 동시에 쓸 수 있어요:
1. **텔레그램**: 기존처럼 텔레그램 앱에서 대화
2. **웹앱(PWA)**: 브라우저로 접속해서 "홈 화면에 추가"하면 진짜 앱처럼 아이콘이 생기고, 전체화면으로 열림

두 방법 다 같은 서버, 같은 Gemini API를 씁니다.

## 1. 로컬에서 테스트

```
pip install -r requirements.txt
```

`.env.example`을 복사해서 `.env`로 만들고 토큰/키 채운 뒤, 환경변수 불러와서 실행:

**Windows (PowerShell):**
```
$env:TELEGRAM_BOT_TOKEN="봇파더가 준 토큰"
$env:GEMINI_API_KEY="AQ.로 시작하는 키"
python app.py
```

콘솔에 `JARVIS 웹앱 시작 (포트 8080)...`과 `JARVIS 텔레그램 봇 시작 (polling)...`이 둘 다 뜨면 성공.

브라우저에서 `http://localhost:8080` 열면 채팅 화면이 보여야 합니다.

## 2. Render에 재배포

기존 Render 서비스를 그대로 쓰면 됩니다. 딱 하나만 바꿔주세요:

- **Settings → Start Command**를 `python main.py`에서 **`python app.py`**로 변경

그리고 GitHub에 새 파일들(`app.py`, `brain.py`, `static/` 폴더 전체)을 올리고 재배포하면 됩니다. `main.py`는 삭제하셔도 됩니다.

## 3. 폰에 "앱"으로 설치하기 (PWA)

1. 안드로이드 크롬 브라우저로 `https://내주소.onrender.com` 접속
2. 오른쪽 위 ⋮ 메뉴 → "홈 화면에 추가" (또는 "앱 설치") 선택
3. 확인하면 홈 화면에 자비스 아이콘이 생김
4. 그 아이콘 누르면 브라우저 주소창 없이 전체화면 앱처럼 열림

이제 텔레그램 없이도, 홈 화면 아이콘으로 바로 자비스에게 말을 걸 수 있어요.
